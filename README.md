# Від чату до агента

Практикум на 60 хвилин для менеджерів проєктів, аналітиків і юристів. Людина обирає свій трек, проходить сім етапів на безпечному симуляторі, а потім збирає власний файл правил і навичку для своїх документів.

**Сторінка:** https://tarasinformation.github.io/vid-chatu-do-agenta/

**Завантажити всі файли проєкту:** [архів .zip](https://github.com/tarasinformation/vid-chatu-do-agenta/archive/refs/heads/main.zip)

У архіві є все, щоб зробити власну версію: правила для агента (CLAUDE.md), навички, вихідні файли сторінки, автотест і документація рішень. Відкрийте папку в Claude Code, і агент одразу знатиме, як із нею працювати.

## Етапи

1. Сходи взаємодії: чат → проєкти → агент документів → агент повної дії, для п'яти екосистем.
2. Один документ, два шляхи: та сама задача в чаті й в агента, розбір помилок чату.
3. Як влаштований агент: модель, інструменти, цикл, інструкції; три файли агента.
4. Правила й навичка: CLAUDE.md з підказками, що поступово зникають; навичка з навмисною помилкою.
5. Судження: що довірити агенту; пошук двох помилок у чернетці.
6. Не тільки Claude: 13 інструментів, стандарти AGENTS.md, SKILL.md, MCP.
7. З чого почати: перша сесія в застосунку, як описати задачу, навчальна папка, власні файли, план на 30 днів.

Курс іде слайдами: вітальне вікно, прогрес, досягнення. На фініші сертифікат, готовий промпт, щоб продовжити навчання з будь-яким ШІ, і стіна анонімних пропозицій. Бонус: як зроблено цей інструмент.

Дизайн: токени [shadcn/ui](https://ui.shadcn.com) (тема Zinc), шрифт [Geist](https://vercel.com/font), криві анімацій [Open Props](https://open-props.style).

## Як змінити

```bash
python3 src/build.py
```

Зібрати сторінку з файлів у `src/`. Перевірити всі модулі:

```bash
python3 -m http.server 8765
```

```bash
src/qa.sh
```

Правила для агента, який працюватиме з проєктом, у [CLAUDE.md](CLAUDE.md). Журнал рішень у [docs/decisions.md](docs/decisions.md).

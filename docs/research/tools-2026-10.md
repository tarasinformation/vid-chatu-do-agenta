# Карта агентних інструментів, станом на 23.10.2026

Звірено з офіційними сторінками. Ринок змінюється щомісяця: оновлювати раз на квартал навичкою `/refresh-tools`. Таблиця на сторінці живе в `src/engine.js` (масив `TOOLS`, сходи `VENDORS`).

## Головні зміни 2026 року

- Cowork вбудовано в звичайний Claude для Pro і Max («Claude Cowork is now just Claude», [claude.com/pricing](https://claude.com/pricing)). Team і Enterprise поки бачать Cowork окремо.
- ChatGPT має Chat, Work і Codex; Work і Codex є навіть у безкоштовному плані ([learn.chatgpt.com/docs/pricing](https://learn.chatgpt.com/docs/pricing)). Work бачить локальні папки лише в застосунку.
- Gemini CLI недоступний приватним користувачам з 18.06.2026, наступник Antigravity ([Google](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/)). NotebookLM перейменовано на Gemini Notebook (16.07.2026).
- Copilot Cowork загальнодоступний з 16.06.2026, працює лише з OneDrive/SharePoint, оплата за використання поверх ліцензії ($30 Enterprise, $21 Business).
- Windsurf став Devin Desktop. Roo Code закрито 15.05.2026. Cursor: Free, Plus $8, Premium $30.
- Manus Desktop працює з дозволеними локальними папками; від Meta відокремлюється.

## Стандарти

- AGENTS.md: Codex, Antigravity, Copilot, Cursor, Devin, Goose та інші. Claude Code читає його, коли поруч немає CLAUDE.md.
- SKILL.md: Claude, Codex/ChatGPT (через плагіни в Work), Antigravity, GitHub Copilot, Cursor, Cline. `.claude/skills` бачать Claude Code, Copilot, Cursor; `.agents/skills` бачать Codex, Antigravity, Copilot, Cursor.
- MCP: майже всі.

# Робочий контекст для сценаріїв

Узагальнено з типових робочих процесів громадських організацій. Лише типи документів, джерел і пасток, без імен, сум, номерів грантів, контактів і назв реальних проєктів.

## Менеджери проєктів

- Документи: проміжні й фінальні наративні звіти донору за обов'язковим шаблоном (англійські заголовки Output), фінансові звіти, щомісячні оновлення, матеріали керівного комітету, звітність щодо міжнародної технічної допомоги.
- Джерела: договір, лограмка з редакціями й доповненнями, трекер індикаторів, витрати за бюджетними лініями, місячні звіти, перелік продуктів.
- Папки: 00_Бриф / 01_Договір / 02_Джерела / 03_Дані / 04_Чернетка / 05_Фінал, README з журналом.
- Типові пастки: звіт за застарілою редакцією лограмки, різні цифри в різних додатках, продукти поза звітним періодом, відсутній місячний звіт.
- Правила: Problem → Solution → Next steps, «щоб що?», біля цифри джерело й дата, прогалини не заповнювати припущеннями.

## Аналітики

- Документи: аналітичні записки, концепт-ноти, оцінки законопроєктів, підсумки опитувань.
- Джерела: вигрузки опитувань з Forms у Excel, звіти партнерів, листи міністерств, попередні чернетки.
- Типові пастки: дублікати й тестові рядки, цифри з чернеток замість первинних даних, посилання на відсутні файли.
- Правила: висновки на першій сторінці, окремий розділ про якість даних, лише знеособлені агреговані дані.

## Юристи

- Документи: проєкти постанов КМУ, наказів, Порядків, порівняльні таблиці, пояснювальні записки, листи про перегляд актів.
- Етапи: внутрішнє погодження → погодження з ЦОВВ → Мін'юст (і за потреби НАЗК) → внесення до КМУ → державна реєстрація наказів.
- Типові пастки: застаріла редакція акта, вставка пункту ламає нумерацію чи відсилки, порівняльна таблиця розходиться з проєктом, неопрацьоване зауваження.

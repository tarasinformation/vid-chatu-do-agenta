## Слабкі місця і наша відповідь

| Проблема | Відповідь у практикумі |
| --- | --- |
| Встановлення на початку | перші 30 хв симулятор у браузері |
| Механіку агента не показують | покроковий цикл, передбачення кроків |
| Приклади про код | три треки на реальних документах |
| Немає безпечного місця | навчальна папка, яку генерує агент |
| Слабкий перенос на свою роботу | генератор власних CLAUDE.md і SKILL.md |
| Перевірка результату в кінці або відсутня | вправа «знайдіть помилки», розбір червоних позначок |
| Прив'язка до одного продукту | механіка + стандарти, продукти окремим шаром з датою |

# Стіна пропозицій: як увімкнути

Сторінка статична, тому пропозиції живуть у Google. Дві таблиці: **приватна** з усіма відповідями і **публічна** лише з тими, що ви схвалили. Посилання на приватну таблицю нікому не даємо.

## 1. Форма (приймає пропозиції без входу)

1. forms.google.com → нова порожня форма. Назва: «Пропозиції до практикуму».
2. Одне питання типу «Абзац»: «Ваша пропозиція». Обов'язкове.
3. Налаштування → Відповіді: **Збирати адреси електронної пошти: не збирати**, «Обмежити однією відповіддю»: вимкнено (інакше вимагатиме входу).
4. Вкладка «Відповіді» → «Зв'язати з Таблицями» → нова таблиця. Це **приватна** таблиця. Її доступ лишається «Обмежений»: лише ви. Ніколи не вмикайте для неї «Усі, хто має посилання». Публічна таблиця побачить її адресу у формулі, тож захищає саме обмежений доступ.
5. Дізнатися адресу й поле: ⋮ → «Отримати попередньо заповнене посилання», впишіть «тест», «Отримати посилання». У посиланні буде `.../forms/d/e/ІД_ФОРМИ/viewform?...&entry.123456789=тест`.
   - `form` = `https://docs.google.com/forms/d/e/ІД_ФОРМИ/formResponse`
   - `entry` = `entry.123456789`

## 2. Модерація в приватній таблиці

Додайте в стовпці C (одразу праворуч від пропозицій) заголовок **«Показати»**. Пишіть `так` навпроти пропозицій, які можна показати всім. Не схвалюйте тексти з іменами, контактами, назвами організацій чи образами.

## 3. Публічна таблиця (лише схвалене)

1. Нова таблиця, наприклад «Стіна пропозицій (публічна)».
2. У клітинці A1:
   ```
   =QUERY(IMPORTRANGE("АДРЕСА_ПРИВАТНОЇ_ТАБЛИЦІ"; "Відповіді у формі (1)!A:C"); "select Col2, toDate(Col1) where Col3 = 'так' label toDate(Col1) 'Дата'"; 1)
   ```
   Дозвольте доступ, коли таблиця попросить. Підлаштуйте діапазон і номер стовпця «Показати», якщо у вас інший порядок (A: позначка часу, B: пропозиція, C: «Показати»).
3. «Поділитися» → «Усі, хто має посилання: читач».
4. `sheet` = ідентифікатор з адреси: `docs.google.com/spreadsheets/d/ІДЕНТИФІКАТОР/edit`.

## 4. Підключити до сторінки

У `src/deck.js` заповніть рядок:

```js
var WALL = { form: "https://docs.google.com/forms/d/e/…/formResponse", entry: "entry.123456789", sheet: "ІДЕНТИФІКАТОР" };
```

Зберіть і перевірте: `python3 src/build.py`, потім `/qa`. Надішліть тестову пропозицію, поставте `так`, оновіть сторінку.

## Що захищає

- Ні імені, ні пошти форма не збирає. На стіні лише дата, без часу, щоб пропозицію не можна було пов'язати з людиною, яка щойно її надіслала.
- Сторінка блокує тексти, схожі на пошту чи телефон, і пускає не більше трьох пропозицій на годину з одного браузера. Це лише підказка для чесних людей: хто захоче, надішле у форму напряму. Тому головний захист у модерації.
- На стіні лише те, що ви схвалили. Приватна таблиця нікому не відкрита.
- Тексти виводяться як звичайний текст, без HTML, тож чужий код на сторінку не потрапить.
- У версії на claude.ai стіна може не завантажитись: це залежить від правил безпеки платформи. Основна адреса для стіни: GitHub Pages.

## Лічильник проходжень

Так само влаштований, але без публічної таблиці. Окрема форма з двома короткими полями «Подія» і «Трек», прив'язана до приватної таблиці. На вкладці «Підсумок» формули COUNTIF / COUNTIFS по стовпцях «Подія» (start / finish) і «Трек». Адреса форми й номери полів у `src/deck.js`, змінна `COUNT`.

# Правила текстів

Еталон: стандарт редагування користувача (навичка `anthropic-skills:text-edit`). Нижче те, що найчастіше ламалось у цьому проєкті.

## Голос

- Діловий, але живий: так говорить досвідчений колега, а не канцелярія і не рекламний буклет.
- Звертання до учня на «ви».
- Короткі речення, конкретні іменники, числа й назви файлів замість загальних слів.
- Дієслова замість віддієслівних іменників: «перевірте», а не «здійсніть перевірку».

## Заборонено

- Тире як розділовий знак. Замість нього кома, двокрапка або крапка. Діапазони (1–4, 01.03–31.07) можна. Знак «—» лише як позначка порожньої клітинки в таблиці.
- «Варто зазначити», «важливо підкреслити», «не просто X, а Y», «саме тут», трійки прикметників, риторичні питання, знаки оклику.
- Русизми й кальки з англійської.
- Пафос і оцінні слова: «революційний», «потужний», «катастрофічний».

## Як писати приклади

- Логіка розділу: проблема → рішення (що зроблено, результат) → що далі. Кожен абзац відповідає на питання «щоб що?».
- Кожна цифра з джерелом і датою: «(трекер, стан на 18.09.2026)».
- Прогалина в даних позначається, а не заповнюється: [ПОТРІБНІ ДАНІ].
- Репліки чату в симуляторі можуть звучати як типовий чат-бот («Із задоволенням допоможу»): це навмисно.

## Терміни

| Термін | Як пояснюємо при першій появі |
| --- | --- |
| агент | ШІ, який сам відкриває файли, робить кроки й перевіряє результат |
| навичка (skill) | збережений рецепт, що запускається однією командою |
| скрипт | невелика програма, яку агент написав для перевірки |
| CLAUDE.md, AGENTS.md | файл правил, який агент читає на початку кожної роботи |
| MCP | спільний стандарт, через який агент підключається до інших програм |
| Manual | режим, у якому агент питає дозволу перед кожною зміною |
| термінал | вікно для текстових команд; для курсу не потрібне |

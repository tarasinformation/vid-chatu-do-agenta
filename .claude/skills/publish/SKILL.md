# Публікація практикуму

1. Спершу виконай навичку /qa. Не публікуй, якщо тест не зелений.
2. GitHub Pages: закоміть зміни й зроби `git push` (index.html оновлюється збіркою). Сторінка оновиться за хвилину-дві.
3. Артефакт у claude.ai: опублікуй `vid-chatu-do-agenta.html` інструментом Artifact за посиланням із CLAUDE.local.md, щоб посилання не змінилося.
4. Додай запис у docs/decisions.md з сьогоднішньою датою: що змінилося і чому.
5. Якщо зміни змістовні, онови документ з аналізом (посилання в CLAUDE.local.md).
6. Нагадай користувачу, що доступ до сторінки відкриває він сам через Share.
